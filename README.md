# Ticketing API

A simple REST API for creating and managing support tickets using Node.js and Express.

## Features

- Create a ticket
- Get all tickets
- Get a ticket by ID
- Validate ticket data
- Return appropriate HTTP status codes
- In-memory ticket storage

## Technologies

- Node.js
- Express.js
- JavaScript
- REST API
